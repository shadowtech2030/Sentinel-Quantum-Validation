# Block 24 Public Evidence Guide

Files in this directory are sanitized public evidence.

Do not add:

- proprietary source code;
- raw internal logs;
- local filesystem paths;
- secrets or credentials;
- private key material;
- exploit details;
- customer data;
- confidential partner information.

The JSON snapshot is suitable for machine-readable public status.

The Markdown milestone is suitable for human review.

Repository-level public hashes should be regenerated after any file changes.
