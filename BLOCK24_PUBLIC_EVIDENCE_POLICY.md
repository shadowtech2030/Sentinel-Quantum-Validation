# Sentinel Quantum — Block 24 Public Evidence Policy

This add-on is intended for a public GitHub validation repository.

## Allowed public evidence

- high-level campaign results;
- sanitized architecture boundaries;
- standards and algorithm names already publicly known;
- public milestone identifiers;
- non-sensitive diagrams;
- validation limits;
- hashes of public artifacts.

## Never publish

- Sentinel source code;
- proprietary policy logic;
- private keys or cryptographic secrets;
- passwords, credentials, tokens or PINs;
- raw internal validation logs;
- sensitive test vectors;
- detailed attack paths;
- customer / production data;
- partner-confidential information;
- internal deployment topology.

## Accuracy rules

Clearly distinguish:

- internal software validation;
- hardware validation;
- simulation-only transition tests;
- external certification.

Do not describe this milestone as:

- invulnerable;
- unbreakable;
- quantum-proof;
- independently certified;
- physically tamper-resistant;
- side-channel certified.

## Hashes

`BLOCK24_PUBLIC_SHA256SUMS.txt` contains SHA-256 hashes of this add-on package only.

A SHA-256 digest is an integrity reference, not a digital signature.
